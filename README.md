# Recruitment-Analytics-Dashboard
A data-driven HR analytics project to evaluate 91 candidates for 5 Social Media Manager / Digital Marketing roles using Excel, Pivot Tables, Scoring Models, and Interactive Dashboards.

**Objective**

To streamline the hiring process by:
- Cleaning raw resume data.
- Scoring candidates on **Experience, Skills, Certifications, and Location**.
- Generating a **Top 5 shortlist** for each role.
- Identifying the **Top 1 candidate** for each role with a detailed rationale.

**Key Features**

- **Candidate Scoring Matrix:** Weighted model (Experience, Skills, Certs, Location) to rank 91 candidates.
- **Pivot Tables:** Analyze Pipeline & Experience Distribution.
- **Interactive Dashboard:** Slicers to filter by Role and Experience.
- **Final Recommendations:** Top 1 candidate per role with detailed rationale.


**Tools Used**

- **Microsoft Excel** (Pivot Tables, Slicers, Formulas)
- **Data Cleaning & Scoring Models**
